# UI & UX Identity

## Obsidian Aesthetics
- **Framework**: Tailwind CSS.
- **Custom Dark Mode**: `#0F0F0F`, `#353535`.
- **Glassmorphism**: Use `backdrop-blur` and semi-transparent backgrounds.
- **Typography**: Sticky Header with "SMART REPAIR" typography.
- **Icons**: Lucide React.
- **Buttons**: Use `bg-brand-gradient` with `style={{ color: 'var(--brand-foreground)' }}` for theme-adaptive contrast (Dark in Light mode, Pearl in Dark mode).
