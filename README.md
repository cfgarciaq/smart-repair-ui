<a name="castellano"></a>
## 🇪🇸 Castellano

Interfaz profesional basada en Glassmorphism para el ecosistema Smart Repair. Este frontend ofrece una experiencia de usuario moderna y fluida para la gestión de servicios técnicos.

### Características
- **React 19 & Vite**: Rendimiento de última generación y tiempos de carga mínimos.
- **Arquitectura de Componentes**: Basada en Shadcn UI y Tailwind CSS para un diseño consistente.
- **Modo Claro/Oscuro**: Soporte nativo con detección automática de las preferencias del sistema.
- **Estética Obsidian**: Diseño premium con texturas granuladas, efectos de desenfoque y acentos neón.
- **Gestión de Datos Dinámica**: Tabla con ordenación en servidor, búsqueda optimizada y paginación ajustable.

### Guía de Instalación
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Configurar el archivo `.env` con la variable `VITE_API_URL`.
4. Iniciar entorno de desarrollo: `npm run dev`

<a name="english"></a>
## 🇺🇸 English

Professional Glassmorphism-based interface for the Smart Repair ecosystem. This frontend provides a modern and fluid user experience for managing technical services.

### Key Features
- **React 19 & Vite**: Cutting-edge performance and minimal loading times.
- **Component Architecture**: Built with Shadcn UI and Tailwind CSS for a consistent design.
- **Light/Dark Mode**: Native support with automatic system preference detection.
- **Obsidian Aesthetics**: Premium design featuring grain textures, blur effects, and neon accents.
- **Dynamic Data Management**: Table with server-side sorting, optimized search, and adjustable pagination.

### Setup Guide
1. Clone the repository.
2. Install dependencies: `npm install`
3. Configure the `.env` file with the `VITE_API_URL` variable.
4. Start development server: `npm run dev`
